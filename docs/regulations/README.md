### Cara Unduh
1. Buka tautan di browser
2. Cari hasil yang sesuai (filter Jenis: Undang-Undang / Peraturan Pemerintah / Peraturan Menteri)
3. Klik judul → halaman detail
4. Klik tombol Download → simpan PDF
5. Letakkan PDF di folder ini (`docs/regulations/`)
